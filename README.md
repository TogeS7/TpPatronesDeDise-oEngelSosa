# Patrones de Diseño 

## Objetivo

Implementar y analizar tres patrones de diseño utilizando ejemplos simples en Java.

## Patrones implementados

- **Singleton:** garantiza una única instancia de una clase.
- **Observer:** permite notificar automáticamente a varios objetos cuando ocurre un cambio.
- **Strategy:** permite cambiar entre diferentes estrategias sin modificar la clase principal.

## Estructura

```text
singleton/   → Patrón Singleton
observer/    → Patrón Observer
strategy/    → Patrón Strategy
